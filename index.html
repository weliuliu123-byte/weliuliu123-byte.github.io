IMAGE PROCESSING // 5-MEMBER TEAM PROJECT My Scope: window_3x3.v & Coordinate Sync

Median–Sobel Image Processing Pipeline — 3×3 Window & Sync

GitHub Repository

What I Worked On

A 5-member team project building a median filtering and Sobel edge detection pipeline in Verilog. Teammates handled the line buffers, filter math, AXI4-Lite integration, and board bring-up.

  • 3×3 Sliding Window (window_3x3.v): Implemented the shift-register window generator that accepts three buffered pixel rows and outputs a parallel 3×3 neighborhood each cycle, with stall-enable and reset support.
  • Pipeline Synchronization: Worked with teammates to align valid signals and pixel coordinates across the cascaded filter stages so border handling stays accurate.
  • Module Verification: Checked window assembly, stall freezing, and valid timing using Vivado simulation waveforms.

DIGITAL COMM // 5-MEMBER TEAM PROJECT My Scope: tx_rx_dsp_top.v, bit_flip_channel.v & Sys Verify

SECDED (8,4) + BPSK Communication Pipeline — Top Integration & Fault Channel

GitHub Repository

What I Worked On

A 5-member team project building a SECDED (8,4) + BPSK communication pipeline in Verilog. Teammates handled the encoder/decoder, BPSK mod/demod, noise injector, and synthesis analysis.

  • Top-Level Integration (tx_rx_dsp_top.v): Wired all six DSP modules together, managing reset, transaction start/done control signals, and stage-to-stage handshakes.
  • Bit-Flip Channel (bit_flip_channel.v): Implemented the LFSR-based channel block to inject clean, single-bit, or double-bit errors into encoded codewords during simulation.
  • System Verification & Docs: Simulated the integrated DSP pipeline and channel module against reference vectors in Vivado XSim, and wrote the system architecture overview.
