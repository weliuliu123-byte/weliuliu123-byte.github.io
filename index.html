COS201 // FPGA COMMUNICATIONS System Integration & Channel RTL

FPGA SECDED (8,4) + BPSK Communication Pipeline

Deterministic FPGA communication system combining Extended Hamming SECDED (8,4) error correction, BPSK modulation/demodulation, LFSR-based channel bit-flip & noise injection, and UART end-to-end verification against a Python golden model.

  • Pipeline Integration (tx_rx_dsp_top.v): Integrated all six DSP stages with stage-to-stage valid/done handshaking, i_start/o_done transaction control, and synchronous active-low reset.
  • Error-Injection Channel (bit_flip_channel.v): Designed deterministic LFSR-driven single-bit and double-bit error injection with collision handling and persistent LFSR state across transactions.
  • System-Level Verification: Verified 154,373 self-checking DSP comparisons (0 errors) across 384 transactions and 24,576 BPSK/noise samples, plus 96 UART end-to-end requests (577 checks, 0 errors).

DGT302 // AMD KRIA KR260 SoC Window & Sync RTL Engineer

Median-Sobel Image Processing Accelerator on KR260

Streaming FPGA SoC accelerator for salt-and-pepper noise removal and Sobel edge detection in Verilog-2001, integrated via AXI4-Lite with the ARM Processing System of the AMD Kria KR260 and validated against Python & ARM C baselines.

  • 3×3 Sliding Window Generator (window_3x3.v): Implemented 3-row shift-register window extraction (p00 to p22) instantiated ahead of both median_3x3 and sobel_3x3, including x/y tracking and border rules.
  • Pipeline Coordinate Synchronization: Co-designed o_valid, o_x, and o_y alignment across the cascaded 2-stage 3×3 pipeline yielding exact N_OUTPUT = (W-4)(H-4) valid edges.
  • Timing Closure & Board Bring-Up: Verified 516,133 datapath checks (0 errors) on 512×512 frames and 24,041 AXI regression checks; met 100 MHz timing on Kria K26 (WNS +0.322 ns) and ran physical KR260 Linux MMIO.
